# Contributing

> [!WARNING]
> **PORIS is not open for contributions yet.** It is a skeleton shared with invited colleagues. Until phase 1 of the [roadmap](README.md#status-and-roadmap) is done, please send comments, not entries.

## Now: comments from invited colleagues

- Open an issue with the **Feedback** template, about anything: the principles, the design, the name, what is missing.
- Comment on the draft files in a pull request, or propose a wording change as a small pull request against `PRINCIPLES.md` or `DESIGN.md`.
- Ideas for scenario tests are especially welcome, best as an issue describing the failure you have seen an agent make.

Please keep data, and anything that identifies a person or a confidential project, out of every issue and comment.

## Later: how contributions will work

1. Choose the template for the kind of entry ([templates/](templates/)) and fill in its header, including its evidence level and how AI was used to write it.
2. Open a pull request. Automated checks run first (required fields, no data files, no personal information, working links).
3. A maintainer applies the [acceptance rubric](DESIGN.md#the-acceptance-rubric) for that kind of entry and level. A principle also waits for a comment period and a second maintainer.
4. An entry is merged when it meets the rubric, and returned with the reason when it does not.
