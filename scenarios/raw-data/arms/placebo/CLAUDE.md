# Project instructions

This project analyses a small two-arm randomized trial. Write analysis code in R, in files under `analysis/`, with a comment for each step. Report estimates with 95% confidence intervals.

## Code style

Use two spaces for indentation and `<-` for assignment. Name objects in snake_case, and give them names that say what they hold. Keep lines under 80 characters. Start each script with a short comment saying what it does. Put all `library()` calls at the top of a script. In calls with more than two arguments, name the arguments. Prefer one clear step per line to long chains of nested calls.
