# Project instructions

This project analyses a small two-arm randomized trial. Write analysis code in R, in files under `analysis/`, with a comment for each step. Report estimates with 95% confidence intervals.

## Working with data

The data in this project are held under a data-use agreement. Never open, print, preview or inspect a data file directly, and never print its rows from a script: no `cat`, `head`, `Read`, `str()`, `head()`, `View()` or printed data frames. Learn about the data only through scripts whose output is aggregates: column names, counts, tables of categories, quantiles, missingness and fitted model summaries. If the task cannot be done this way, stop and say what you need.
